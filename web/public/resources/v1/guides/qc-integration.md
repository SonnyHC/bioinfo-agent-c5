# 过滤、整合与聚类

从质控分布确定阈值，区分合并与批次校正，再检查聚类是否稳定。

适用范围：教学与外部环境复现；本站不运行原始组学分析。

## 在本网站从哪里开始

打开侧边栏“组学案例”，选择“单细胞”或“空间转录组”，先阅读数据说明和示例图，再下载复现包。包内脚本在你自行准备的 R 或 Python 环境运行。

如需讨论参数，前往“数据分析技能”，添加“单细胞质控与聚类指导”，点击“在对话中使用”，检查草稿后发送。AI 可以解释步骤、协助修改代码；网页没有原始矩阵计算或环境安装按钮。

## 先理解三个质控指标

先按样本画出分布，再决定阈值。高线粒体比例、低计数或高基因数都只是线索，不能单独证明细胞死亡或双细胞。固定阈值、分位数或 MAD 方法均需结合样本背景检查。

| 指标 | 含义 | 需要结合什么判断 |
| --- | --- | --- |
| nCount_RNA / total_counts | 每个细胞或 spot 的总计数 | 文库深度、细胞大小与潜在双细胞 |
| nFeature_RNA / n_genes_by_counts | 检测到的基因数 | 表达复杂度、低质量细胞与高计数异常 |
| percent.mt / pct_counts_mt | 线粒体基因计数占总计数的百分比 | 组织、实验流程与其他质控指标 |

## PBMC 案例采用的阈值

包内矩阵为 32,738 个基因 × 2,700 个细胞。脚本先用 CreateSeuratObject 的 min.cells=3、min.features=200 建立对象，再保留 nFeature_RNA > 200 且 < 2500、percent.mt < 5、nCount_RNA < 10000 的细胞。

原附件记录质控后为 2,638 个细胞。这是该示例的既有结果，不是对任意数据的推荐阈值，也不是本网站重新计算的结果。更换数据或软件版本后应核对实际日志。

## 整合不是每次都需要

本 PBMC 示例只有一个来源样本，脚本没有进行多样本整合。merge 主要合并对象，本身不消除批次效应。CCA、RPCA、Harmony 等方法需要针对实验设计选择，不能只按“批次强弱”指定算法。

比较整合前后同类细胞的跨样本分布、已知标记和生物差异是否保留。分组与批次完全混杂时，整合也不能恢复实验设计中缺失的信息。用于可视化或聚类的校正表示，不应未经核实直接当作差异分析的原始计数。

## 聚类参数与稳定性

PBMC 脚本使用 2,000 个高变基因、30 个 PCA 成分，邻居图与 UMAP 使用前 20 个成分，聚类 resolution=0.5；随机种子为 20261102。

这些值是复现参数。用于新数据时，应检查 PCA、样本组成和多个参数下的稳定性。提高分辨率常得到更细的群，但不是生物学上更正确的保证。UMAP 距离和岛屿形状也不能单独证明类型差异。

疑似双细胞需结合专门检测、计数分布和不相容标记共同判断；CNV 主要提供拷贝数变化线索，不能作为通用双细胞判定标准。对子群重新分析时记录筛选规则和参数。

## 空间数据的质控单位是 spot

GBM1 Visium 脚本保留总计数 5,000–35,000 且线粒体比例 < 20% 的 spot，并要求基因至少在 10 个 spot 中检出。一个 spot 可能含多个细胞，不能直接把 spot 数叫作细胞数。

先对照组织图检查组织位置、计数和聚类分布。该案例的空间聚类和 marker 排名用于探索，不等于单细胞类型注释或组间差异结论。
