# 细胞注释注意事项与结果解读

结合多个标记、表达比例和组织背景核对候选标签，保留不确定性。

适用范围：教学与外部环境复现；本站不运行原始组学分析。

## 先分清这四张图说明什么

PBMC FeaturePlot 按每个基因阳性表达的第 99 百分位数缩放并截断到 1；色条为相对表达。UMAP 灰色虚线是 98% 数据椭圆，极小 cluster 使用包络圈，均非生物边界。

| 案例图 | 可以检查 | 不能直接得出 |
| --- | --- | --- |
| QC 小提琴图 | 输入对象的基因数、计数和线粒体比例分布 | 不同实验组之间的差异；本例只有 All cells |
| UMAP clusters | 当前算法得到的聚类结构 | 经过验证的细胞类型或生物学边界 |
| Marker DotPlot | 各 cluster 的表达比例与平均 log 归一化表达 | 图上 marker 组合名称就是 cluster 的最终身份 |
| Marker FeaturePlot | 同一 UMAP 坐标上的基因表达分布 | 不同基因的颜色强度可以直接定量比较 |

## 用多组标记交叉核对

先判断大谱系，再讨论亚型。检查候选类型的多个阳性标记、与其他类型相冲突的标记，以及这些基因在 cluster 中的表达比例。单个 CD4 基因并非 CD4 T 细胞独占标记，稀疏表达也可能造成漏检。

把 UMAP、DotPlot、FeaturePlot 与组织背景放在一起看。混合标记可能来自双细胞、环境 RNA、过粗聚类或过渡状态，不能遇到矛盾就强行命名。无法判定时保留 Unknown、混合群或候选标签。

## 核对抽样、数据层与检验实现

是否降采样、每群保留多少细胞、使用何种数据层与检验，必须以实际代码和日志为准。本网站没有“每群默认 500 个细胞”的注释热图模块。

PBMC marker_summary.csv 记录的是预设 marker 的 pct 和 avg，不包含 P 值或 logFC，不能改称差异基因检验结果。Presto、FindMarkers 与其他实现的筛选、表达层和统计选项可能不同，不承诺结果必然一致。

## 比例与背景用于复核，不用于迎合预期

细胞比例受采样、组织解离、富集步骤和质控策略影响。背景知识可帮助发现异常，但不能为了得到预期“故事”而调整标签或排除细胞。

对不同条件的比例比较，需要样本层面的重复和适当统计设计，不能把一个样本中大量细胞当作大量独立个体。

## 如何表述 T 细胞状态

若候选 T 细胞群表达 PDCD1、CTLA4 等基因，可记录为与活化或耗竭相关的转录特征，并进一步检查多基因程序、组织背景及其他证据。仅凭两个标记不能证明功能耗竭，更不能推出免疫治疗失败的因果机制。

包内 PBMC 示例并没有肿瘤治疗分组。不要把教学假设写成这份数据已经得到的发现。

## 在网页中开展复核

到“数据分析技能”添加“细胞注释结果复核”，在对话草稿中说明物种、组织、cluster、候选类型和已观察到的证据。对话当前不读取案例图片内容，若需要讨论图中的细节，应把观察或表格数值明确写出。

小型 CSV 结果表可以通过“数据与绘图”导入，仍受 2 MB 限制；原始 10x / H5AD / Visium 文件请在外部环境处理。不要为了适应上传限制，截取数据后仍声称是完整矩阵分析。
