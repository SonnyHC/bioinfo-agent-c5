## 用户明确要求

### 移除独立工作台界面

以现有 AI 对话主界面为基础组织导航。截图中的工作台不再作为独立产品界面出现，也不再要求用户先跳到这套工作台才能安装技能、安装环境或编辑图表。

将已有导入、数据检查、方案确认、结果和历史能力接入新的主界面。界面组件可以拆分复用；保留已有原始文件、运行记录和后端能力。

### 主侧边栏加入数据分析技能

在主侧边栏提供清晰的“数据分析技能”入口，让用户查看可安装的分析技能、用途和状态，并完成安装或启用相应分析能力。详细列表可在主内容区或抽屉中展开，但入口须直接位于主侧边栏。

当前 `companion/catalog.json` 是随代码提供的四类技能目录；现有“已安装”状态实际上主要反映对应分析环境是否就绪。接手时需要明确技能可用状态与环境就绪状态的关系，分别呈现用户要求的两个入口。第三方技能市场、任意 URL 安装等不属于本次已经确定的范围。

### 主侧边栏加入分析环境

提供独立的“分析环境”入口。用户可以为所选分析一键安装对应虚拟环境，查看未安装、安装中、已就绪、失败等状态，并在失败时查看原因、重试。

复用现有本地安装流程：Python 使用 uv 创建隔离环境并安装技能依赖；R 使用 renv 管理包环境。技能与环境之间要有明确对应关系，避免用户不知道某项分析需要安装哪个环境。首次启动助手所需的 Node / uv，以及 R 本体的前置要求，应与网页里的环境安装动作区分清楚。

### 主侧边栏预留参考基因组

在主侧边栏增加“参考基因组”入口，当前只预留入口。

本次不添加基因组内容、物种列表、版本、下载地址、下载流程或后台接口。入口可设为尚不可用，保持没有实质内容，后续由用户补充要求。

### 新增图表生成后的调参界面

用户已经生成图表后，应能从该结果直接进入参数编辑界面。打开时加载这张图对应的源数据、模板和实际运行参数，不需要重新导入数据或重新从图例目录开始。

基本流程：

1. 打开某次已完成的图表结果，点击“调整参数”。
2. 同时查看当前图表与参数面板，参数初值来自该次运行的方案记录。
3. 修改参数后点击更新或重新生成，显示运行状态和新的图表。
4. 保存并下载与新图对应的参数、数据处理记录和导出文件。
5. 保留原始数据和原图结果；新结果能追溯到原结果及本次参数变更。

用户本轮没有逐项指定可调参数。接手时可优先支持标题、坐标轴标签、配色、字号、点大小、透明度、图幅和导出分辨率等常见绘图参数，并根据图种提供适用项；这是实施建议，不能写成用户已经确认的参数清单。

字段映射、分组、缺失值处理、FASTQ 读取数量、H5AD 细胞数量等会影响分析数据的参数，需要重新生成转换预览并由用户确认。保留现有数据检查和 R 脚本信任确认。展示参数与数据处理参数应有清楚的区别。所有重新生成都由用户触发，并沿用现有 `POST /runs` 的 `confirm:true` 确认契约；AI 工具不能自行批准执行。

参数控件必须实际影响本地生成的图和下载文件。当前后端没有统一支持上述全部外观参数，需要同步扩展参数校验、绘图逻辑和复现记录。H5AD 的现有 `color` 参数表示细胞注释字段，并不是配色方案。任意用户 R 脚本也尚无通用外观参数协议；应按模板的实际能力提供编辑项。

## 验收要求

- 主要使用路径不再出现截图中的独立工作台，主侧边栏可以直接进入数据分析技能和分析环境。
- 技能状态、环境安装进度和失败重试能反映实际后端状态。
- “参考基因组”只存在侧边栏预留入口，没有填充内容或下载功能。
- 从一张已完成的图进入调参，能加载该图的真实参数并生成新图；下载结果与页面显示一致，旧图和原始数据保留。
- 修改会影响数据处理的参数后重新预览并确认，未确认时不执行；R 信任门槛保持有效。
- 导入、历史记录、模型设置、本地助手连接继续可用；旧方案和结果链接能正确恢复。
- 检查桌面与窄屏布局，安装或绘图进行中避免重复提交，错误能够被用户看到。

基线版本已有 61 项通过的测试及真实本地绘图记录，详见 [验证记录](validation.md)。这不能替代新界面的验收；改版后运行相关回归并实际验证“安装环境 → 生成图 → 调参 → 重新生成 → 下载 → 再次打开”。真实模型调用、正式域名部署等当前验证范围也以该记录为准。
