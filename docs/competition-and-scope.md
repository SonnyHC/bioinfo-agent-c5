## 3. 从初步分析中提炼的需求

需求来源为用户提供的 `C5.zip` 内 `C5/README.md`，这里只保留实施所需的摘要，不分发原始压缩包、安装包或完整内部草案。

目标用户是需要整理实验表格并绘图的学生和科研人员。主要困难是字段命名、宽表与长表、分组和缺失值的差异。工作流应让用户看清转换过程，保留原始数据，并能带走可复现的结果。

首版优先跑通以下流程：

1. 选择图表模板，导入 CSV 或 Excel 表格。
2. 检查字段、类型、空值和分组；展示原始数据预览。
3. 提出字段映射或宽长转换方案，展示转换后的预览。
4. 用户确认转换与绘图参数，再执行本地绘图。
5. 查看实际生成的图片，导出图片、处理后数据、代码、参数和处理记录。

Agent 应负责理解任务、提出可检查的操作方案和解释错误。数值转换与绘图由有明确输入约束的工具完成；无法确定字段含义时保留问题，不猜测实验含义。涉及删除数据、缺失值填补、标准化或分组重命名时，应显示具体影响并由用户选择。

首版使用官方 DeepSeek Harness 的插件机制，借鉴 BioDSH 的本地科研工作流；具体依赖版本、接口和许可由实现文档记录。原型是否真正调用了模型、是否只使用固定样例，必须在测试记录中分别说明。

## 4. 首版优先级

| 范围 | 首版约定 |
| --- | --- |
| 核心演示 | 用同一箱线图模板分别处理长表和宽表，保留每个样本的散点与分组信息 |
| 输入 | CSV、Excel；格式、行列数和文件大小限制由实现明确给出 |
| 图表扩展 | 核心流程通过后再扩展散点图、直方图等；界面只展示实际支持的操作 |
| 数据处理 | 支持显式字段映射与可预览的结构转换；原始数据保留 |
| 执行位置 | 本机；浏览器界面可以连接本地服务，不要求先部署公共网站 |
| 导出 | 实际图片、最终数据、可运行代码、参数与处理记录；记录来源和运行版本 |
| 后续阶段 | FASTQ、H5AD、R 脚本、单细胞分析、差异表达、火山图、生存分析和 UMAP，需单独明确输入及分析前提 |

FASTQ 是序列数据，H5AD 是带注释的矩阵容器，R 文件是代码，三者不能作为普通表格格式直接互换。首次原型不应仅因接受了扩展名，就宣称支持对应生信流程。虚拟环境自动安装、技能市场和桌面安装包也是独立能力，未实现前不列作完成项。

## 5. 验收与实测记录

先用公开或合成的非敏感数据建立可人工核对的基线，再邀请实际用户试用。公开数据保留来源和使用条件，合成数据标注为合成。

| 场景 | 可检查的通过条件 |
| --- | --- |
| 长表 | 分组、数值、样本数与原表一致；零值被保留 |
| 等价宽表 | 转成长表后，逐组数值与基线长表一致；原始文件内容不变 |
| 缺失值 | 提示缺失位置及其影响；未确认处理时不悄悄删除或填补 |
| 字段含糊 | 无法确定的映射可以修改或要求澄清；不直接宣称识别正确 |
| 错误类型或非法参数 | 给出可行动的错误信息；不生成看似成功的空图或假结果 |
| 导出与复跑 | 新环境按导出的依赖说明执行代码，得到相同数据和相同绘图参数的结果 |
| 真实模型调用 | 有请求成功、工具执行与产物的记录；密钥不进入日志、导出包或仓库 |

记录任务起止时间、成功/失败、字段映射是否正确、修正次数、最终样本数和人工操作步骤。时间比较使用相同数据、任务和完成标准，报告样本量与个体差异。只有实测后才给出准确率或节省时间等指标；一次成功演示不能代表普遍准确性。
