# 四篇组学教程

使用教程与案例页的“专题教程”共用一个文档阅读组件。首页直接显示四个并列标签，按过滤、整合与聚类 → 细胞注释 → 差异分析 → 富集分析排列；原独立“网站操作”栏目已删除。

## 内容来源

正文使用 `docs/tutorial-sources/` 中的四份用户提供 Markdown，原件字节完整保留：

- `01_过滤、整合与聚类.md` 全文形成第一个专题。
- `04_细胞注释.md` 在前、`02_细胞注释.md` 在后，合并为细胞注释。
- `03_差异表达与功能富集分析.md` 按方法、参数、结果解读、问答与参考链接的归属拆成差异分析、富集分析；通用总结和说明在两篇保留。

这里只调整标题层级、合并、拆分及排版，没有精简或修订科学内容。原文的第三方平台操作说明也保持原样，页面末尾注明来源；这些说明不表示本站新增对应功能。此次整理未进行科学内容核验。原有技能指导单独保存在 `web/src/data/skill-guides.json`，避免原文重排影响已安装技能的 ID 与阅读材料。

## 阅读布局

使用现有网站配色，按文档样式呈现正文、分级标题、列表、行内代码和表格。桌面右侧目录随滚动高亮，点击可跳转；窄屏使用折叠目录，宽表格在自身区域横向滚动。四个标签支持方向键、Home、End，外部参考链接在新标签页打开。

## 生成与校验

```sh
python3 scripts/prepare-omics-guides.py
node --import tsx --test tests/guide-markdown.test.ts tests/tutorial-content.test.ts tests/omics.test.ts
```

生成器从仓库中的原件生成 `omics-guides.json`、四篇可下载 Markdown、教程 ZIP 与两份 manifest 的包信息。`docs/tutorial-source-map.json` 记录所有来源行段，覆盖 230 条非空原文行。完整 V1.0 资源生成器也调用同一教程生成器。

ZIP 内含四篇整理稿和 `originals/` 下四份原件。页面渲染和单篇下载使用同一份 Markdown。旧的教程截图不再用于这四篇文档；案例图片与完整 V1.0 原始资料不变。
