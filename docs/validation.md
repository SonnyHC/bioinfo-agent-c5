# 首版验证记录

日期：2026-10-26。测试环境：macOS Apple Silicon、Node 26、Python 3.12。以下结果使用仓库内合成样例，不代表真实科研数据或方法学有效性已经验证。

## 已执行

- TypeScript 类型检查和 Vite 生产构建。
- Python 引擎 22 项测试：宽长表一致性、明确缺失值策略、原值与原始文件保持、重复表头/列名、伪数值与非有限值、Excel 公式、图表适用性、原始极值完整展示、宽表坐标标签、依赖检测、导出和复跑。
- 六种图表实际输出 PNG、SVG、PDF。复现测试独立执行导出的 analysis.py，PNG 与原输出逐字节一致。
- HTTP 集成测试：真实文件上传、拒绝不支持类型和额外参数、确认前禁止执行、Agent 不能自批、重复提交幂等、并发请求单次执行、本地隐藏目录中的图片/ZIP下载、源文件摘要保持和跨站请求拒绝。
- Harness 插件 5 项测试：挂载到真实 Cordis / ToolRuntime 并注册五个工具；连接、ID、端点和参数边界。
- 官方 Harness 主机烟测：启动固定版本、安装并启用本地 bundle、列出 C5 preset、创建真实工作区与会话并挂载 C5。
- 浏览器实际操作：合成宽表导入、转换预览、确认运行、查看真实图片、从页面下载复现包及核对 ZIP 完整性；桌面与 390px 窄屏布局检查。
