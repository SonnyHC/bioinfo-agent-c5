### 真实浏览器流程

使用 Codex 内置浏览器访问 `http://127.0.0.1:5173`，助手使用项目内 `.local/companion-preview`。Tabbit 启动器缺少可执行文件，未将其启动失败当作 UI 验证结果。

1. 在主侧边栏配对助手。点击 FASTQ「安装技能」后观察到“技能已安装 / 环境未安装”，随后从「分析环境」一键安装，显示实际任务日志并最终就绪。
2. 实际安装单细胞 Python 环境；安装中切换页面、刷新后能读取继续运行的安装状态；完成后真实 H5AD 自动化测试全部通过。
3. 通过页面载入 40 条合成 FASTQ 记录，预览、勾选确认、生成原图。未确认时运行按钮禁用。
4. 从结果点击「调整参数」，恢复已保存参数；修改标题、X 轴标签、配色、PNG dpi，并把最多读取数由 10000 改为 20。重新预览显示 20 条记录及前缀取样提示。
5. 勾选确认后再次修改数据参数，原方案与确认立即失效，执行按钮消失；重新预览后确认框恢复未勾选。
6. 再次确认生成独立新结果。`provenance.json` 正确记录父运行 ID 和五项参数变化；原图处理表仍为 40 行，新图为 20 行；原始 FASTQ 的 SHA-256 与方案一致。
7. 实际点击 `chart.png` 下载。下载文件与助手保存的新 PNG 逐字节一致，**1920 × 1440，49,916 字节**，SHA-256 为 `c7d0fd0a0fc2f036cab48243ac88727f748b50b364e1929c1901d80107a83496`。
8. 刷新新结果并重新打开参数编辑，标题 `Read length edited`、配色 `plasma`、dpi `240` 等实际参数正确恢复。旧 `/workbench?run=…` 恢复改版前的箱线图和默认参数，旧 `/workbench?plan=…` 恢复原方案且仍需确认。
9. 「让 AI 帮我选择参数」回到 `/?dataset=…`，显示同一真实文件名和 ID；未发送真实模型请求。
10. 最终代码另验证「调整字号 → 预览 → 刷新草稿链接 → 再次确认生成」。草稿恢复原图与字号 12，确认框未勾选；助手重启后重新配对，所有已安装环境和历史结果仍可读取。
